# Modifier-candidate gene list for NF / schwannomatosis
# ---------------------------------------------------------------------------
# Anchored on the four core disease genes: NF1, NF2, SMARCB1, LZTR1.
# Three layers of inclusion per anchor:
#   (1) Direct physical interactors  -- proteins shown to bind the anchor
#       (literature-confirmed protein-protein interactions / complex members).
#   (2) Canonical pathway effectors   -- well-established signaling pathway
#       members in which the anchor functions (downstream/upstream signaling).
#   (3) Published modifier / risk loci -- genes implicated by NF cohort studies
#       in phenotype severity or tumor-progression risk.
#
# This is a curated STARTER list, not exhaustive. It mixes strong and weaker
# evidence -- categories below reflect that. For a systematic interactor
# expansion, see the STRING recipe at the bottom of this file.
#
# Format: one HGNC symbol per line. '#' starts a comment.
# Pass with: --modifier-genes R/nf_modifier_genes.txt
# ---------------------------------------------------------------------------
